# aitimus_test

Delphi VCL приложение для учёта людей и их контактов с использованием базы данных Firebird (embedded сервер).

## Задача
В базе данных (предпочтительная СУБД Firebird) нужно хранить информацию по Человеку (Фамилия, Имя, Отчество, Пол, Дата рождения) и его Контактам (телефоны, электронные почтовые адреса, домашний адрес и т.п.). И люди, и контакты в базе проверяются на уникальность. Работа с данными из вне происходит исключительно через хранимые процедуры.
Создать в Delphi интерфейс для пользователя. Пользователю должны быть доступны:
- просмотр и добавление записи о Человеке
- просмотр контактов выбранного Человека, добавление контактных данных
Создать в базе процедуру для выборки записей о людях с фильтром по критериям: пол, частичное совпадение ФИО от 2-х символов, частичное совпадение по контакту от 4х символов подряд, возраст. Фильтры могут как отсутствовать, так и быть установлены в любой комбинации.

## Назначение
Программа позволяет хранить информацию о людях (Фамилия, Имя, Отчество, Пол, Дата рождения) и их контактных данных (телефоны, электронные почтовые адреса, домашний адрес и т.п.). Люди и контакты в базе проверяются на уникальность. Работа с данными извне выполняется исключительно через хранимые процедуры.

## Требования
- ОС: Windows
- Среда разработки: Delphi с поддержкой FireDAC (рекомендуется Delphi XE7 и новее)
- СУБД: Firebird 3.0+ (embedded, файл `fbclient.dll` лежит в корне проекта)
- Библиотеки: FireDAC (входит в состав Delphi)

## Структура проекта
```
aitimus_test.dpr          — основной проект (точка входа)
aitimus_test.dproj        — проект Delphi
DataModule.pas / .dfm     — подключение к БД (TFDConnection), наборы данных qPerson, qContact, qType
MainForm.pas / .dfm       — форма авторизации (frmAuthorize): подключение к БД, сохранение настроек
Person.pas / .dfm         — основная форма (frmPerson): список людей, контакты, фильтры, добавление/удаление
Types.pas / .dfm          — справочник типов контактов (frmTypes)
migration\migr_0001.sql   — скрипт создания таблиц и хранимых процедур Firebird
config.ini                — файл настроек подключения (создаётся автоматически)
fbclient.dll              — встроенный клиент Firebird
```

## База данных
Скрипт миграции `migration\migr_0001.sql` создаёт:

### Таблицы
- `PERSON` — люди (ID, SURNAME, NAME, SECOND_NAME, SEX, DOB)
- `CONTACT` — контакты (ID, VAL, PERSON_ID, CONTACT_TYPE_ID)
- `CONTACT_TYPE` — типы контактов (ID, NAME)

### Ограничения уникальности
- `PERSON_UNIQUE` — уникальное сочетание ФИО + Пол + Дата рождения
- `CONTACT_UNIQUE` — уникальное сочетание Значение + Человек + Тип контакта
- `CONTACT_TYPE_UNIQUE` — уникальное имя типа контакта

### Хранимые процедуры
- `SP_GET_PERSONS` — выборка людей с фильтрами (пол, ФИО, контакт, возраст)
- `SP_ADD_PERSON` — добавление человека (возвращает P_ID)
- `SP_DEL_PERSON` — удаление человека и его контактов
- `SP_GET_CONTACTS` — контакты выбранного человека
- `SP_ADD_CONTACT` — добавление контакта (возвращает P_ID)
- `SP_DEL_CONTACT` — удаление контакта
- `SP_GET_TYPES` — список типов контактов
- `SP_ADD_TYPE` — добавление типа контакта
- `SP_DEL_TYPE` — удаление типа контакта

## Запуск миграции базы данных

Перед первым запуском приложения необходимо применить скрипт миграции `migration\\migr_0001.sql`, который создаёт таблицы, ограничения уникальности и хранимые процедуры.

### 1. Сделайте бэкап существующей базы (если она уже есть)
```bash
gbak -b -user sysdba -password masterkey "Путь\к\базе.fdb" "Путь\к\резервной_копии.fbk"
```

### 2. Примените скрипт миграции
Используйте утилиту `isql` из комплекта Firebird. Обязательно укажите кодировку клиента `WIN1251`, чтобы русские символы в скрипте передались корректно.

```bash
isql -user sysdba -password masterkey -charset WIN1251 "Путь\к\базе.fdb" < migration\migr_0001.sql
```

Если `isql.exe` не в системном PATH, укажите полный путь, например:
```bash
"C:\Program Files\Firebird\Firebird_3_0\bin\isql.exe" -user sysdba -password masterkey -charset WIN1251 "J:\dev\delphi\firebird_data\ITIMUS.fdb" < migration\migr_0001.sql
```

### 3. Проверьте результат
После успешного выполнения в базе должны появиться таблицы `PERSON`, `CONTACT`, `CONTACT_TYPE` и хранимые процедуры `SP_*`. Проверить можно запросом:
```sql
SELECT RDB$RELATION_NAME FROM RDB$RELATIONS WHERE RDB$SYSTEM_FLAG = 0;
SELECT RDB$PROCEDURE_NAME FROM RDB$PROCEDURES;
```

### Важные замечания
- Скрипт использует `GENERATED BY DEFAULT AS IDENTITY` и тип `BOOLEAN`, поэтому требуется **Firebird 3.0 или новее**.
- Если таблицы уже существуют, `CREATE TABLE` вернёт ошибку. Перед повторным запуском миграции удалите старые таблицы или восстановите базу из бэкапа.
- Все текстовые поля созданы с `CHARACTER SET WIN1251`. В настройках подключения Delphi (`FDConnection.Params`) должен быть указан `'CharacterSet=WIN1251'`, иначе кириллица отобразится некорректно.

## Интерфейс

### frmAuthorize (авторизация)
- Ввод логина, пароля, пути к файлу базы данных
- Кнопка подключения с 3 попытками при ошибке
- Сохранение последних настроек в `config.ini`

### frmPerson (основная форма)
- `gPerson` — таблица людей (Имя, Фамилия, Отчество, Пол, Дата рождения)
- `gContact` — таблица контактов выбранного человека (Значение, Тип)
- Панель фильтров: Пол, ФИО, Возраст, Контакт
- Кнопки: Добавление человека, Удаление человека, Добавление контакта, Удаление контакта, Сброс фильтров, Поиск
- Меню: Типы контактов, Выход

### frmTypes (справочник типов контактов)
- Список типов контактов (Email, Телефон и т.п.)
- Добавление / удаление типа

## Работа с приложением

### Авторизация
При запуске открывается окно входа. Укажите путь к файлу базы Firebird, имя пользователя (по умолчанию `sysdba`) и пароль. После успешного подключения параметры сохраняются в `config.ini` для последующих запусков.

### Логирование
При открытии наборов данных (`qPerson`, `qContact`) в файл `query_log.txt` записывается текст SQL-запроса и значения параметров. Это позволяет отлаживать работу фильтров и хранимых процедур.

### Создание типов контактов
В главном меню выберите «Типы контактов». Откроется справочник, в котором можно:
- Добавить новый тип (например, «Email», «Мобильный телефон», «Домашний адрес»)
- Удалить выбранный тип (если он не используется контактами людей)

Типы контактов используются при добавлении контактных данных к человеку.

### Создание человека
На основной форме в группе «Данные» заполните поля:
- Фамилия, Имя, Отчество (обязательно)
- Пол (выберите из списка)
- Дата рождения (обязательно)
Нажмите кнопку «Добавить». Человек будет сохранён в базе через хранимую процедуру `SP_ADD_PERSON` и появится в списке.

### Создание контакта человека
1. Выберите человека в списке расположенным в середине формы.
2. На основной форме в левой таблице выберите тип контакта и введите значение (например, номер телефона или адрес электронной почты).
3. Нажмите «Добавить». Контакт будет привязан к выбранному человеку и появится в таблице контактов.
4. Чтобы удалить контакт, выделите его и нажмите «Удалить».

### Поиск людей
На панели фильтров можно задать любые комбинации критериев:
- **Пол** — Мужской или Женский
- **ФИО** — введите минимум 2 символа для частичного совпадения по фамилии, имени или отчеству
- **Возраст** — укажите возраст для фильтрации
- **Контакт** — введите минимум 4 символа подряд для поиска людей по их контактным данным (телефон, email, адрес)

Нажмите «Поиск», чтобы применить фильтры. Кнопка «Все люди» сбрасывает все фильтры и показывает полный список.

## Фильтрация людей
В хранимой процедуре `SP_GET_PERSONS` реализована выборка с любым набором фильтров:
- **Пол** — Мужской / Женский
- **Частичное совпадение ФИО** — от 2 символов
- **Частичное совпадение по контакту** — от 4 символов подряд
- **Возраст** — фильтрация по возрасту

Фильтры могут отсутствовать или комбинироваться в любой сочетании.

## Настройка подключения
При первом подключении параметры (путь к БД, пользователь) сохраняются в `config.ini` рядом с исполняемым файлом. При повторном запуске загружаются автоматически. Пароль рекомендуется не сохранять в открытом виде.

## Запуск
1. Убедитесь, что `fbclient.dll` находится рядом с `aitimus_test.exe`.
2. Запустите `aitimus_test.exe`.
3. В окне авторизации укажите путь к базе Firebird (например, `firebird_data\ITIMUS.fdb`), логин `sysdba` и пароль.
4. Нажмите «Соединиться».
