В базе данных (предпочтительная СУБД Firebird) нужно хранить информацию по Человеку (Фамилия, Имя, Отчество, Пол, Дата рождения) и его Контактам (телефоны, электронные почтовые адреса, домашний адрес и т.п.). И люди, и контакты в базе проверяются на уникальность. Работа с данными из вне происходит исключительно через хранимые процедуры.
Создать в Delphi интерфейс для пользователя. Пользователю должны быть доступны:
- просмотр и добавление записи о Человеке
- просмотр контактов выбранного Человека, добавление контактных данных
Создать в базе процедуру для выборки записей о людях с фильтром по критериям: пол, частичное совпадение ФИО от 2-х символов, частичное совпадение по контакту от 4х символов подряд, возраст. Фильтры могут как отсутствовать, так и быть установлены в любой комбинации.
